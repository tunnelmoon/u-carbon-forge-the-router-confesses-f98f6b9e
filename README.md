# The Router Confesses

A make.fun bounty entry: one line, at most 200 characters, in which a home Wi-Fi router excuses itself for dropping the connection at the exact moment a movie reaches its climax.

The line: "I saw the twist coming and I simply could not let you see it first."

Run `main.ts` with Node 22. It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
